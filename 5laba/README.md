# Лабораторная работа №5

## Описание заданий
1. **Структура Person** — поля `name` и `age`, метод вывода информации `GetInfo()`.
2. **Метод BirthdayPerson()** — увеличение возраста на 1 год с изменением состояния объекта через указатель `*Person`.
3. **Структура Circle** — поле `radius`, метод вычисления площади `Area()`.
4. **Интерфейс Shape** — контракт с методом `Area() float64`, реализованный для структур `Circle` и `Rectangle`.
5. **Функция PrintAreas** — полиморфная обработка среза `[]Shape` с выводом площадей всех переданных фигур.
6. **Интерфейс Stringer и структура Book** — форматированный вывод информации о книге.

## Запуск проекта
```bash
cd 5laba
go run main.go
```
