# Лабораторная работа 4

1. **Создание карты:** Инициализация `map[string]int`, добавление нового человека и вывод списка.
2. **Средний возраст:** Функция подсчета среднего значения возраста по карте.
3. **Удаление:** Удаление элемента из карты по ключу через `delete()`.
4. **Верхний регистр:** Построчный ввод строки и перевод в верхний регистр (`strings.ToUpper`).
5. **Сумма чисел:** Чтение чисел через пробел и вычисление их суммы (`strings.Fields`, `strconv.Atoi`).
6. **Разворот среза:** Считывание чисел и вывод в обратном порядке (`slices.Reverse`).

## Структура

* `maputils/` — функции работы с map (задания 1–3).
* `io/` — консольный ввод/вывод и обработка данных (задания 4–6).
* `main.go` — вызов всех функций.

# Запуск
go run main.go
