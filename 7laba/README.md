# Лабораторная работа №7

Сетевое программирование на Go: TCP-сервер и клиент, HTTP-сервер с middleware, чат на WebSocket.

## Описание заданий
1. **TCP-сервер** — слушает порт (`net.Listen`), принимает соединения (`Accept`), построчно читает сообщения клиента (`bufio.Scanner`), выводит их на экран и отправляет подтверждение получения.
2. **TCP-клиент** — подключается к серверу (`net.Dial`), отправляет введённое пользователем сообщение, ждёт ответ сервера и после его получения закрывает соединение.
3. **Асинхронная обработка** — каждое соединение обрабатывается в отдельной горутине (`sync.WaitGroup`). Graceful shutdown по Ctrl+C (`signal.NotifyContext`): сервер перестаёт принимать новых клиентов, предупреждает подключённых, даёт им 5 секунд (`SetReadDeadline`) и дожидается завершения всех обработчиков.
4. **HTTP-сервер** — маршруты `GET /hello` (приветствие) и `POST /data` (принимает JSON, выводит содержимое в консоль, проверяет корректность данных). Graceful shutdown через `http.Server.Shutdown`.
5. **Маршрутизация и middleware** — маршрут `GET /status/{user}` с параметром в пути, ответ в JSON. Middleware `Logger` логирует метод, URL и время выполнения каждого запроса.
6. **Чат на WebSocket** — клиенты подключаются по `ws://`, сообщение любого клиента рассылается всем подключённым. Список клиентов хранится в хабе под мьютексом; при остановке сервер вежливо закрывает все соединения (код 1001).

## Структура
* `tspserver/` — TCP-сервер (задания 1, 3).
  * `internal/server.go` — прослушивание порта, цикл `Accept`, остановка.
  * `internal/handler.go` — обработка одного клиента.
* `tspclient/` — TCP-клиент (задание 2).
* `httpserver/` — HTTP-сервер (задания 4, 5).
  * `internal/handlers.go` — обработчики маршрутов.
  * `internal/middleware.go` — логирующий middleware.
* `webSocket/` — WebSocket-чат (задание 6), библиотека `github.com/gorilla/websocket`.
* В каждой программе `cmd/main.go` — точка входа.

## Запуск
Все серверы по умолчанию слушают `:8080`, поэтому запускаются по очереди. Адрес меняется флагом `-addr`.

```bash
cd 7laba

# задания 1–3: сервер и клиент в разных терминалах
go run ./tspserver/cmd
go run ./tspclient/cmd

# задания 4–5
go run ./httpserver/cmd

# задание 6
go run ./webSocket/cmd
```

## Проверка

**TCP-сервер** можно проверить и без клиента: `nc localhost 8080`.

**HTTP-сервер:**
```bash
curl localhost:8080/hello
curl -X POST localhost:8080/data -H 'Content-Type: application/json' -d '{"name":"Егор","age":20}'
curl localhost:8080/status/Егор
```

**WebSocket-чат:** в Postman — New → WebSocket, адрес `ws://localhost:8080/ws`, Connect. Для проверки рассылки открыть два подключения: сообщение из одного приходит в оба.
