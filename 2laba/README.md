Лабораторная работа 2:
Описание заданий:
1.	Определение четности числа: Функция determinantParity проверяет остаток от деления на 2 и возвращает "Четное" или "Нечетное".
2.	Проверка знака числа: Функция determinantNumber через if-else возвращает "Positive", "Negative" или "Zero".
3.	Вывод чисел от 1 до 10: Функция cycle заполняет и возвращает срез []int числами от 1 до 10 с помощью цикла for.
4.	Длина строки: Функция determinantLength вычисляет точное число символов строки через utf8.RuneCountInString.
5.	Структура Rectangle: Объявлена структура Rectangle с полями width и height, функцией ввода setArea и методом getArea() для расчета площади.
6.	Среднее значение: Функция average считывает два целых числа и вычисляет вещественное среднее через float64.
