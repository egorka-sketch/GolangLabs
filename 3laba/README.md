Лабораторная работа 3.
1.	Факториал (mathutils): Реализована функция вычисления факториала через цикл.
2.	Ввод числа: Считывание значения через fmt.Scan и расчет факториала.
3.	Разворот строки (stringutils): Разворот строки через срез рун []rune для поддержки UTF-8.
4.	Массив чисел: Создание и заполнение массива [5]int случайными числами через math/rand/v2.
5.	Срез из массива: Создание слайса, добавление значений через append и удаление элемента по индексу.
6.	Самая длинная строка: Поиск самого длинного слова в срезе с подсчетом символов через utf8.RuneCountInString.
